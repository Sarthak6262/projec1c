# projec1c
Number Guessing Game
A simple and interactive C program where you try to guess a randomly generated number between 1 and 100. Perfect for beginners learning basic concepts of C like loops, conditionals, user input, and random number generation.

🧠 How It Works
The program generates a random number between 1 and 100.

The user is prompted to guess the number.

After each guess, the program gives feedback whether to guess higher or lower.

The game continues until the correct number is guessed.

It then displays the number of attempts taken.

📋 Features
Random number generation using rand() and srand()

Input via scanf

Feedback loop with hints (higher/lower)

Keeps count of attempts

Friendly user messages

🛠️ Technologies Used
Language: C

Compiler: GCC or any standard C compiler
